# Healthcare Billing and Insurance Claims Intelligence Using MySQL

## Project Overview

This project analyzes healthcare billing and insurance claims data using MySQL to identify claim denials, approval trends, billing discrepancies, and payment patterns.

It demonstrates SQL skills and business analysis techniques relevant to Data Analyst and Business Analyst roles.

## Business Problem

Healthcare organizations may experience claim denials, delayed approvals, incomplete documentation, and differences between billed, approved, and paid amounts.

This project uses relational data and SQL queries to analyze these issues and recommend improvements.

## Objectives

- Analyze insurance claim statuses.
- Identify common claim denial reasons.
- Compare billed, approved, and paid amounts.
- Evaluate payer and provider performance.
- Calculate healthcare billing and claims KPIs.
- Generate actionable business recommendations.
